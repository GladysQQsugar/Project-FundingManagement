# 基金项目管理系统

一个基于 Vue 3 + Element Plus + ECharts 开发的基金项目可视化管理系统。

## 主要功能

- **管理驾驶舱**: 项目数据可视化分析，包括基金分布、阶段分布、产业方向分布等。
- **项目库管理**: 项目全景列表，支持多维度筛选（名称、基金、阶段、行业等）、分页加载及导出。
- **数据导入导出**: 支持 CSV 格式数据的批量导入与全量导出，方便数据迁移与备份。
- **性能优化**: 针对 5000+ 条数据进行了搜索防抖、列表分页、图表缓存等多项性能优化。
- **系统字典**: 统一管理行业分类、项目阶段等运行参数。

## 本地运行说明

1. **安装依赖**:
   ```bash
   npm install
   ```

2. **启动开发服务器**:
   ```bash
   npm run dev
   ```

3. **构建生产版本**:
   ```bash
   npm run build
   ```

## 技术栈

- **前端框架**: Vue 3 (Composition API)
- **UI 组件库**: Element Plus
- **图表库**: ECharts
- **构建工具**: Vite
- **样式方案**: Tailwind CSS
